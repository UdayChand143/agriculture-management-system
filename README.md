# Agriculture Management System

A web-based Agriculture Management System developed using Java, JSP, Servlets, JDBC, and MySQL. This application helps farmers manage their agricultural activities efficiently through a user-friendly interface.

## Features

* Farmer Registration and Login Authentication
* Secure Session Management
* Add Crop Details
* View Available Crops
* Buy Crops
* Farmer Dashboard
* Logout Functionality
* MySQL Database Integration
* Responsive and Modern User Interface

## Technologies Used

* Java
* JSP (Java Server Pages)
* Servlets
* JDBC
* MySQL
* HTML5
* CSS3
* Font Awesome
* Apache Tomcat

## Database

The project uses MySQL as the backend database to store farmer information and crop details.

## Project Modules

### Farmer Module

* Register as a new farmer
* Login securely
* Manage crop information
* View dashboard statistics

### Crop Module

* Add crop details
* View crop records
* Purchase crops
